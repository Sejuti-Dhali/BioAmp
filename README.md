# BioAmp
Interactive educational non-inverting amplifier simulator based on Multisim Lab 2, Problem 1.2 (page 3, Figures 1.5–1.6).

Open `index.html` locally or upload the contents of this folder to a GitHub repository and enable Pages from the main branch, root folder. No dependencies or build step.

Default: R1=1 kΩ, R2=2 kΩ, 0.707 Vrms, 60 Hz, ±5 V. Ideal gain=3; predicted output RMS=2.121 V, peak≈2.9995 V. These are calculated values, not measurements. Original Multisim screenshot is included separately. The analytical model uses ideal gain and hard rail clipping, not a device-specific SPICE model. Educational use only.
